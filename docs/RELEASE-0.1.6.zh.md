## 0.1.6 更新内容

### 内核升级

- **内核升级到 0.1.2-rc.1**（官方 npm 包）：适配 rc.1 精简后的依赖结构（移除 46 个旧包）；新功能包括会话流默认折叠过程内容、token 用量与耗时显示、全文回合导航、子代理模型选择、ACP 标准能力补齐、实验性 Inspector 与 Web Preview、send_message 双向消息传递
- web profile 依赖树重写（补充 peer 依赖）；修复 koffi 未提升、pnpm store 版本不一致、CLI/SDK bundle 误入导致的 duplicate loader 等依赖问题
- 插件安装策略改进：git 源自动解析最新 release tag（避免装到默认分支旧代码）、加载验证失败自动尝试备用源、git 构建脚本 allowBuilds 自动授权
- 卸载改进：卸载前结束应用进程，robocopy 空目录镜像法递归删除（支持 .pnpm 超长路径），resources 不再残留

### 归档与回滚（重点修复）

- **恢复归档修复**：dsh-workspace 缺失 unarchiveSession 方法导致「恢复归档」报「工作区服务不可用」，已补齐并支持幂等恢复
- **热回滚 URL 拼接修复**：serverUrl 含 token 查询串导致路径拼接错误，热回滚请求此前始终无法到达插件路由——**热回滚自上线以来首次真正可用**
- 热回滚可靠性增强：超时 4s→15s、失败自动重试、新增 READONLY 分支（先释放会话再走磁盘回滚），大会话回滚不再误触发整机重启
- 回滚页性能修复：用户消息提取改为异步逐帧解压（130 条消息 7.9s→200ms）+ mtime 缓存，不再阻塞内核导致服务假死
- 回滚结果跨刷新提示；回滚列表拆分「已归档 / 未归档」分组并与工作区 20s 轮询联动；下拉样式优化（序号等宽、40 字预览、悬停全文）
- 系统注入消息（runtime 快照 / 子代理消息 / system-reminder）在会话卡片与下拉中统一显示为「（系统注入消息）」，不再露出内部文本

### 检查点（对话与文件联动回滚）

- 适配 rc.1 会话格式（文件参数移至 tool/call 事件）：修复预览恒显示「该消息未修改任何文件」；消息已被历史回滚截断时降级为按检查点整体恢复
- **大工作区快照修复**：git 快照排除 .m2-repo / .gradle 等构建缓存目录、超时 30s→120s、关闭 autocrlf（消除 CRLF 警告洪水）、错误信息压缩——修复大型 Java/Maven 项目中检查点创建超时导致 **AI 全部工具被阻断**的问题；恢复时这些目录原样保留不误删
- 预览与恢复范围严格一致：untracked 新文件如实出现在预览中（此前不可见但会被删除）；gitignored 文件（.env、构建产物）回滚时保留
- ACTIVE_TURN 保护：有会话正在生成回复时拦截检查点回滚（与消息回滚一致），不再静默杀掉生成中的回复
- 保护检查点（guard）独立预览语义：「恢复它即撤销那次回滚对文件的修改，对话保持不变」

### 插件与安全

- **卸载防线**：「已安装插件」中的内核依赖与 bundle 层标「系统」徽标且不可卸载（误卸会导致应用无法启动）；默认插件不受影响
- **卸载联动清理**：卸载插件时自动移除 cordis.patch.yml 中引用该包的 MCP 服务器条目，不再残留僵尸配置
- 插件更新生效验证：pnpm 偶发「added 0」假成功（版本未变）现在如实报「更新未生效」并说明原因
- 插件市场未安装项的「禁用」改为「屏蔽」（与默认插件的禁用语义区分）；未安装项不再显示误导性按钮

### 其他

- 退出程序时同步强制结束内核进程树（taskkill /T /F），彻底解决退出后孤儿进程
- 打包/部署一致性：源码打包 → 安装 → 启动与部署版逐字节一致（打包期 no-console 补丁固化）
- 回收站描述、MCP 状态用词、回滚页计数口径等文案与布局修正

## 下载

- `DeepSeek.Harness.Setup.0.1.6.0.exe` — 安装版（选择安装目录，开始菜单/桌面快捷方式，静默添加 Defender 排除）
- `DeepSeek.Harness.0.1.6.0.Portable.exe` — 便携版（解压到 exe 旁的 `app\`，版本不符自动重新解压）
